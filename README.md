# Evospaice  — The AI‑Driven Evolutionary Space

Evospaice is a system that:
- embeds DNA sequences into a high‑dimensional manifold
- reconstructs evolutionary geometry without alignments
- builds phylogenetic trees from embedding distances
- quantifies biodiversity using branch lengths
- performs species identification via nearest‑neighbor retrieval
- unifies BLAST‑like lookup with phylogenetic scaling
- enables alpha and beta diversity metrics directly from embeddings

It’s not just a classifier.  
It’s not just a tree builder.  
It’s a new computational substrate for evolutionary biology!
