Bottom-Up Hierarchical DNA Tree Construction

A Guided Semi-Supervised Architecture Combining Taxonomic Taxonomy with Continuous DNA Sequence Embeddings

Executive Summary

Constructing comprehensive Trees of Life from millions of DNA sequences presents a major computational and biological bottleneck. Traditional alignment-based phylogenetic methods (e.g., Maximum Likelihood via RAxML or Neighbor-Joining on pairwise distance matrices) scale at $\mathcal{O}(N^2)$ to $\mathcal{O}(N^3)$ computational time and require full Multiple Sequence Alignment (MSA), which breaks down across highly divergent or unalignable genomic regions.

Conversely, relying purely on established taxonomy (e.g., NCBI Taxonomy, Insect Genome / Barcode Database) fails to capture fine-grained sequence variation, sub-species lineage structure, or newly sequenced unannotated strains. Furthermore, taxonomic classifications frequently contain polyphyletic errors or historical misannotations.

This technical proposal details a Hierarchical Bottom-Up Semi-Guided Architecture. The core innovation is to anchor global tree topology using known taxonomic ranks while driving fine-grained intra-taxon branching and upward node propagation using high-dimensional sequence embeddings (derived from genomic foundation models such as OmniDNA-20M, Nucleotide Transformer, DNABERT, or HyenaDNA).

1. Conceptual Framework & Architecture

The system operates as a recursive bottom-up tree builder that decomposes a massive global alignment problem into scalable, parallel local sub-problems, propagating synthesized representations up the taxonomic ladder.

======================================================================================== GLOBAL ROOT (Domain / Life) ======================================================================================== ▲ │ Phase 3: Inter-Taxon Parent Tree Assembly [ Family / Order Level Nodes ] ▲ │ Phase 2: Upward Node Propagation [ Genus Level Representatives ] ▲ │ Phase 1: Intra-Taxon Subtree Assembly [ Species / Strain Subtrees (Local Tree) ] ▲ │ DNA Embeddings: e_i ∈ ℝᵈ [ Sequence 1 ] [ Sequence 2 ] [ Sequence 3 ] ... [ Sequence m ] ========================================================================================

Mathematical Problem Formulation

Let $\mathcal{S} = \{s_1, s_2, \dots, s_N\}$ be a dataset of $N$ DNA sequences. Each sequence $s_i$ is mapped to a continuous vector $e_i = f_\theta(s_i) \in \mathbb{R}^d$ via a pretrained genomic transformer $f_\theta$. Furthermore, each sequence is associated with a hierarchical taxonomic path $\mathcal{T}(s_i) = [r_1, r_2, \dots, r_K]$ corresponding to taxonomic ranks (e.g., Strain $\rightarrow$ Species $\rightarrow$ Genus $\rightarrow$ Family $\rightarrow$ Order $\rightarrow$ Class $\rightarrow$ Phylum $\rightarrow$ Domain).

Key Architectural Advantage: Computational Complexity Reduction
Instead of calculating a single global pairwise distance matrix of size $N \times N$ taking $\mathcal{O}(N^2 \cdot d)$ time, the bottom-up approach partitions sequence processing into $K$ local species clusters of size $m_k \ll N$. The computational cost reduces to $\mathcal{O}\left(\sum_{k=1}^K m_k^2 \cdot d\right)$, yielding speedups of several orders of magnitude while preserving local evolutionary topology.

Three-Phase Algorithmic Pipeline

  1. Phase 1: Intra-Taxon Subtree Resolution (Base Layer)
    For every lowest-level taxon $T_k$ (e.g., Species level), collect all constituent sequence embeddings $S^{(k)} = \{e_1, e_2, \dots, e_{m_k}\}$. Compute a local pairwise distance matrix $D_{ij} = d(e_i, e_j)$ and resolve a fine-grained local phylogenetic tree $L_k$ using Neighbor-Joining (NJ), FastME, or Hierarchical Agglomerative Clustering (HAC).
  2. Phase 2: Upward Node Propagation (Representation Synthesis)
    To propagate information from child subtree $L_k$ to its parent node at the next taxonomic rank (e.g., Genus), compute a single synthesized node representation $R_k$. Rather than naive averaging, $R_k$ can be modeled as a point vector (medoid, weighted centroid) or a continuous probability distribution $(\mu_k, \Sigma_k)$.
  3. Phase 3: Inter-Taxon Parent Tree Assembly
    At parent rank $P$ containing child representatives $\{R_1, R_2, \dots, R_p\}$, compute inter-taxon distances using the appropriate metric space (e.g., Cosine distance for point vectors, 2-Wasserstein distance for probability distributions). Construct the inter-taxon tree topology and graft the child subtrees $L_k$ onto their corresponding leaves.

2. Comprehensive Node Propagation Strategies

The choice of mathematical object used to represent a resolved subtree $L_k$ when propagating upward directly impacts how downstream parent trees handle variance, sequence noise, and evolutionary drift.

2.1 Strategy 1: Simple Centroid Vector

Calculates the arithmetic mean of sequence embeddings within the subtree:

$$\mu_{\text{centroid}} = \frac{1}{m} \sum_{i=1}^{m} e_i$$
  • Properties: Computationally lightweight ($\mathcal{O}(m \cdot d)$). Assumes cluster is unimodal and spherical in Euclidean space.
  • Limitation: Highly sensitive to extreme sequence outliers. In high-dimensional space, vector averaging causes manifold collapse—pulling the centroid vector into empty feature space off the true sequence manifold.

2.2 Strategy 2: Medoid (Partitioning Around Medoids / PAM)

Selects the actual sequence embedding in the subtree that minimizes the sum of distances to all sibling sequence embeddings:

$$e_{\text{medoid}} = \arg\min_{e_i \in S^{(k)}} \sum_{j=1}^{m} d(e_i, e_j)$$
  • Properties: Fully robust to sequence noise and extreme outliers. Guarantees that the representative vector corresponds to a real biological sequence.
  • Limitation: Ignores the overall variance spread of the cluster, reducing a diverse taxon to a single point sample.

2.3 Strategy 3: Phylogenetically Weighted Centroid

Weights each sequence embedding $e_i$ inversely proportional to its evolutionary redundancy using Gerstein-Sonnhammer-Chothia (GSC) branch weights or Star Decomposition weights derived from the local tree $L_k$:

$$\mu_{\text{weighted}} = \sum_{i=1}^{m} w_i e_i \quad \text{where} \quad \sum_{i=1}^{m} w_i = 1$$
  • Properties: Mitigates public database sampling bias (e.g., 10,000 sequenced clinical isolates of E. coli O157:H7 vs 2 environmental strains). Overrepresented strains receive smaller weights $w_i$.

2.4 Strategy 4: Distributional Representation (Gaussian / 2-Wasserstein Space)

Represents subtree $L_k$ as a multi-variate continuous probability distribution $\mathcal{N}(\mu_k, \Sigma_k)$, where $\mu_k \in \mathbb{R}^d$ is the mean vector and $\Sigma_k \in \mathbb{R}^{d \times d}$ is the regularized covariance matrix describing intra-taxon genetic variance:

$$\mu_k = \frac{1}{m} \sum_{i=1}^{m} e_i, \quad \Sigma_k = \frac{1}{m-1} \sum_{i=1}^{m} (e_i - \mu_k)(e_i - \mu_k)^T + \epsilon I_d$$

The distance between two child node distributions $\mathcal{N}_1(\mu_1, \Sigma_1)$ and $\mathcal{N}_2(\mu_2, \Sigma_2)$ is calculated using the 2-Wasserstein Distance (Optimal Transport Metric):

$$W_2^2\left(\mathcal{N}_1, \mathcal{N}_2\right) = \|\mu_1 - \mu_2\|_2^2 + \text{Tr}\left(\Sigma_1 + \Sigma_2 - 2 \left(\Sigma_1^{1/2} \Sigma_2 \Sigma_1^{1/2}\right)^{1/2}\right)$$
  • Properties: Preserves clade variance. A taxon with high sequence variability maintains a larger Wasserstein footprint, preventing diverse taxa from being compressed into misleadingly small point representations.

2.5 Strategy 5: Fréchet Means on Non-Euclidean Manifolds

If embeddings are normalized onto a unit hypersphere $\mathbb{S}^{d-1}$ (common for Cosine similarity) or mapped to a hyperbolic Poincaré ball $\mathbb{B}^d$ (ideal for hierarchical graphs), Euclidean means pull vectors off the manifold. The Fréchet Mean minimizes manifold geodesic distance $d_{\mathcal{M}}$:

$$\mu_{\text{Fréchet}} = \arg\min_{p \in \mathcal{M}} \sum_{i=1}^{m} d_{\mathcal{M}}(p, e_i)^2$$

Detailed Strategy Comparison Matrix

3. Complete Python Implementation

The following Python script simulates high-dimensional DNA embeddings across a multi-level taxonomy, extracts representations using Centroid, Medoid, and 2-Wasserstein Distributional methods, constructs linkage matrices, and renders side-by-side dendrogram comparisons.

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial.distance import pdist, squareform
from scipy.cluster.hierarchy import linkage, dendrogram
from sklearn.metrics.pairwise import cosine_distances

# Set random seed for exact reproducibility
np.random.seed(42)
d = 32  # Feature dimension (e.g., compressed genomic embedding)

# ---------------------------------------------------------
# 1. Simulate Multi-Level Taxonomy & Sequence Embeddings
# ---------------------------------------------------------
taxonomy = {
    "Genus_A": {"Species_A1": 6, "Species_A2": 6},
    "Genus_B": {"Species_B1": 6, "Species_B2": 6},
    "Genus_C": {"Species_C1": 6, "Species_C2": 6},
}

sequences = {}
metadata = []
seq_idx = 0

for genus, species_dict in taxonomy.items():
    genus_center = np.random.randn(d)
    for species, count in species_dict.items():
        # Species cluster around genus center
        species_center = genus_center + np.random.randn(d) * 0.5
        for i in range(count):
            seq_id = f"seq_{seq_idx:02d}"
            # Add intra-species variance + deliberate outlier on sequence 0
            noise = 0.2 if i > 0 else 1.2
            emb = species_center + np.random.randn(d) * noise
            sequences[seq_id] = emb
            metadata.append({"id": seq_id, "genus": genus, "species": species})
            seq_idx += 1

species_list = sorted(list({m["species"] for m in metadata}))

def get_species_embeddings(metadata, sequences, species_name):
    seq_ids = [m["id"] for m in metadata if m["species"] == species_name]
    return np.array([sequences[sid] for sid in seq_ids])

# ---------------------------------------------------------
# 2. Extract Node Representatives Across Strategies
# ---------------------------------------------------------
centroids, medoids, distributions = {}, {}, {}

for sp in species_list:
    embs = get_species_embeddings(metadata, sequences, sp)
    
    # Strategy 1: Centroid
    centroids[sp] = np.mean(embs, axis=0)
    
    # Strategy 2: Medoid (PAM)
    dist_mat = squareform(pdist(embs, metric="cosine"))
    medoid_idx = np.argmin(dist_mat.sum(axis=1))
    medoids[sp] = embs[medoid_idx]
    
    # Strategy 3: Distributional Representation (Mean + Regularized Covariance)
    mu = np.mean(embs, axis=0)
    sigma = np.cov(embs, rowvar=False) + np.eye(d) * 1e-4
    distributions[sp] = (mu, sigma)

def wasserstein_2_distance(dist1, dist2):
    # Computes exact 2-Wasserstein distance between two Gaussian distributions
    mu1, sigma1 = dist1
    mu2, sigma2 = dist2
    mean_diff = np.sum((mu1 - mu2) ** 2)
    # Matrix trace calculation for covariance term
    cov_term = np.trace(sigma1 + sigma2 - 2 * np.sqrt(np.abs(sigma1 @ sigma2)))
    return np.sqrt(max(0.0, mean_diff + cov_term))

# ---------------------------------------------------------
# 3. Build Inter-Species Pairwise Distance Matrices
# ---------------------------------------------------------
def get_condensed_distances(species_list, representations, metric="cosine"):
    n = len(species_list)
    condensed = []
    for i in range(n):
        for j in range(i + 1, n):
            sp1, sp2 = species_list[i], species_list[j]
            if metric == "wasserstein":
                d_val = wasserstein_2_distance(representations[sp1], representations[sp2])
            else:
                d_val = cosine_distances([representations[sp1]], [representations[sp2]])[0, 0]
            condensed.append(d_val)
    return np.array(condensed)

dist_centroid = get_condensed_distances(species_list, centroids, metric="cosine")
dist_medoid = get_condensed_distances(species_list, medoids, metric="cosine")
dist_wasserstein = get_condensed_distances(species_list, distributions, metric="wasserstein")

# Compute Hierarchical Linkage (UPGMA / Average Linkage)
Z_centroid = linkage(dist_centroid, method='average')
Z_medoid = linkage(dist_medoid, method='average')
Z_wasserstein = linkage(dist_wasserstein, method='average')

# ---------------------------------------------------------
# 4. Render Comparative Visualizations
# ---------------------------------------------------------
fig, axes = plt.subplots(1, 3, figsize=(18, 5.5))

dendrogram(Z_centroid, labels=species_list, ax=axes[0], leaf_rotation=45)
axes[0].set_title("Centroid Vector (Cosine Distance)")
axes[0].set_ylabel("Tree Height / Distance")

dendrogram(Z_medoid, labels=species_list, ax=axes[1], leaf_rotation=45)
axes[1].set_title("Medoid Vector (Cosine Distance)")

dendrogram(Z_wasserstein, labels=species_list, ax=axes[2], leaf_rotation=45)
axes[2].set_title("Distributional (2-Wasserstein Distance)")

plt.tight_layout()
plt.show()

4. Formal Evaluation & Quality Framework

Evaluating the fidelity of a semi-guided hierarchical DNA tree requires measuring three independent validation dimensions: Biological Accuracy, Embedding Metric Fidelity, and Structural Robustness.

4.1 Biological & Taxonomic Alignment (Supervised Validation)

Compares the reconstructed embedding tree $T_{\text{eval}}$ against benchmark phylogenies $T_{\text{ref}}$ (e.g., curated Insect genome/barcode dataset or RAxML trees built on core marker genes).

  • Robinson-Foulds (RF) Split Distance: Measures the symmetric difference between unrooted splits induced by $T_{\text{eval}}$ vs $T_{\text{ref}}$:
    $$\text{RF}(T_{\text{eval}}, T_{\text{ref}}) = |B(T_{\text{eval}}) \setminus B(T_{\text{ref}})| + |B(T_{\text{ref}}) \setminus B(T_{\text{eval}})|$$
    Lower values indicate higher topological congruence. Normalized $\text{nRF} \in [0, 1]$.
  • Normalized Kendall-Colijn Tree Distance: Compares tree topology and clade depths by calculating path lengths from leaves to their Most Recent Common Ancestor (MRCA). Unlike RF distance, Kendall-Colijn rewards near-miss topologies.
  • Taxonomic Monophyly Score: Evaluates clade purity for every taxon $k$ at rank $R$:
    $$\text{Monophyly}(C_k) = \frac{|\text{Leaves in } C_k \text{ belonging to Taxon } k|}{|\text{Total Leaves in Subtree } C_k|}$$

4.2 Metric Space Fidelity (Unsupervised Validation)

Determines how accurately distances on the discrete tree reflect true continuous distances in embedding space.

  • Cophenetic Correlation Coefficient (CPCC): Calculates the Pearson correlation coefficient between pairwise distances in original embedding space $D_{ij} = d(e_i, e_j)$ and cophenetic tree distances $C_{ij}$ (branch height where leaves $i$ and $j$ merge):
    $$c = \frac{\sum_{i Target score: $c > 0.85$. Higher correlation proves minimal metric distortion.
  • Hyperbolic Distortion / Metric Stress: Measures relative quadratic distortion introduced by embedding graph metrics:
    $$\text{Stress} = \frac{\sum_{i < j} \left(d_T(s_i, s_j) - d_{\text{emb}}(e_i, e_j)\right)^2}{\sum_{i < j} d_{\text{emb}}(e_i, e_j)^2}$$
  • Mean Absolute & Percentage Error (MAE / MAPE): Measures direct distance magnitude distortion across sequence pairs:
    $$\text{MAE} = \frac{2}{N(N-1)} \sum_{i < j} |d_T(s_i, s_j) - d_{\text{emb}}(e_i, e_j)|$$
  • $k$-Nearest Neighbor ($k$-NN) Preservation Ratio: Measures local neighborhood topology preservation by calculating the overlap of $k$-nearest neighbors in embedding space vs. tree distance:
    $$\text{Precision}@k = \frac{1}{N} \sum_{i=1}^N \frac{|\mathcal{N}_{\text{emb}}^k(i) \cap \mathcal{N}_{\text{tree}}^k(i)|}{k}$$

4.3 Structural Robustness & Stability Metrics

  • Bootstrap Support Analysis: Injects isotropic Gaussian noise $\mathcal{N}(0, \sigma^2 I)$ or embedding feature dropout into the sequence embeddings and re-runs bottom-up assembly $B=100$ times. Node support percentage is calculated per internal branch (equivalent to Felsenstein's bootstrap).
  • Subsampling Invariance: Randomly drops $10\%$ to $30\%$ of sequences from local species subtrees and measures the stability of parent-level clade assignments using the Rand Index.

5. Scalability & Operational Considerations

5.1 High-Dimensional Distance Concentration

In high dimensions ($d \ge 768$), Euclidean distances suffer from concentration of measure (distances between arbitrary pairs become nearly identical). Recommendation: Use Cosine Distance ($1 - \cos\theta$) or Normalized Euclidean Distance on $\ell_2$-normalized vectors.

5.2 Sub-Quadratic Scaling with Approximate Nearest Neighbors (ANN)

For lowest-level taxa containing $> 100,000$ sequence isolates, standard pairwise distance calculation becomes slow ($\mathcal{O}(m^2)$). Integrate HNSW (Hierarchical Navigable Small World) graphs or FAISS indexing to build approximate $k$-NN graphs in $\mathcal{O}(m \log m)$ time prior to local tree linkage.

5.3 Soft Hierarchy & Polyphyly Re-annotation

If sequence embedding evidence strongly contradicts existing taxonomy (e.g., a species clade embedding $R_i$ assigned to Genus A is significantly closer in 2-Wasserstein distance to Genus B), the system flags the branch as polyphyletic and offers dynamic re-attachment options.

7. Top-to-Bottom (Divisive) Approaches & Paradigm Comparison

While the primary architecture described in this specification uses a bottom-up (agglomerative) scheme, tree construction can also be approached from the top-to-bottom (divisive) direction. Understanding the trade-offs between these two paradigms is essential when designing large-scale tree-building systems across diverse sequence datasets (such as Insect DNA barcode databases).

7.1 Top-to-Bottom (Divisive) Conceptual Formulation

A top-to-bottom approach starts with the entire set of $N$ DNA sequence embeddings $S = \{e_1, e_2, \dots, e_N\}$ at the global domain or order root, and recursively partitions the continuous sequence space downward into finer sub-clades:

  • Global Partitioning: Uses global manifold features (e.g., Bisecting $k$-Means, Spectral Bisection on graph Laplacians, or Divisive Analysis / DIANA) to split sequence clusters into major macro-lineages (Order $\rightarrow$ Family).
  • Recursive Downward Decomposition: Recursively splits each child node downward until reaching species or strain boundaries.
  • Leaf Resolution: Constructs local subtrees at the leaves once sequence variance falls below a predefined threshold.

7.2 Architectural Trade-Off Comparison

Dimension Top-to-Bottom (Divisive) Bottom-Up (Agglomerative)
Primary Strength Captures broad global topology and major macro-evolutionary splits across divergent taxa. Provides maximum resolution and fidelity for fine-grained strain and intra-species variants.
Computational Complexity $\mathcal{O}(N \log N)$ using fast recursive bisection (e.g., Bisecting $k$-Means). $\mathcal{O}\left(\sum m_k^2\right)$ partitioned local computations across local species blocks.
Error Propagation Risk High Risk: Misclassification at top-level splits propagates down to all child subtrees. Low Risk: Sequence noise and misannotations remain isolated within local child subtrees.
Variance & Outlier Preservation Isolates distant lineages early; prevents deep ancestral branch distortion. Requires advanced node representations (e.g., Medoids for noise, 2-Wasserstein for variance).
Best Application Scenario Mapping unguided global sequence relationships across highly divergent orders/phyla from scratch. Building high-precision trees anchored by established taxonomy (e.g., Insect barcode datasets).

7.3 The Hybrid V-Cycle Paradigm

Optimal Engineering Compromise: Hybrid Top-Down / Bottom-Up Scheme
To combine the global topology optimization of top-down partitioning with the local precision of bottom-up aggregation:
  1. Top-Down Phase: Recursively split the dataset into macro-clusters using fast spectral graph cuts or Poincaré hyperbolic embeddings down to the Genus/Species level.
  2. Bottom-Up Phase: Build exact distance-based subtrees at the leaf level using sequence embeddings (OmniDNA-20M, Nucleotide Transformer, HyenaDNA) and propagate node representations (Medoids, Wasserstein bounds) back upward to refine branch lengths and resolve polyphyly.

8. Concrete Case Study: Resolving Cryptic Insect Taxa

To illustrate why a bottom-up approach anchored by an established taxonomic backbone outperforms naive global clustering, consider the challenge of resolving cryptic butterfly subspecies within the genus Heliconius (Order Lepidoptera, Family Nymphalidae).

8.1 Biological Context & Objective

Suppose we process $N = 1,000$ DNA barcode sequence embeddings $e_i \in \mathbb{R}^d$ generated by OmniDNA-20M from tropical butterfly specimens:

  • Known Taxonomic Skeleton: Order Lepidoptera $\rightarrow$ Family Nymphalidae $\rightarrow$ Genus Heliconius.
  • Biological Goal: Resolve fine-grained genetic variations ($< 0.5\%$ divergence) between morphologically identical sister species (Heliconius erato vs. Heliconius melpomene) and their regional subspecies (e.g., H. erato cyrbia vs. H. erato hydara).

8.2 Step-by-Step Bottom-Up Workflow

  1. Base Layer Intra-Species Tree Building: Group sequence embeddings strictly by their lowest trusted species tag (H. erato). Compute a local pairwise cosine distance matrix $D_{ij} = d(e_i, e_j)$ across the $m = 500$ H. erato sequences to resolve sub-species lineage branching.
  2. Upward Node Propagation: Synthesize the resolved H. erato local subtree into a representative Medoid vector $e_{\text{medoid}}$ (to reject sequence noise) or a Gaussian distribution $(\mu_{\text{erato}}, \Sigma_{\text{erato}})$ in 2-Wasserstein space to preserve population genetic variance.
  3. Parent Genus Attachment: Compute the Wasserstein inter-taxon distance $W_2\left(\mathcal{N}_{\text{erato}}, \mathcal{N}_{\text{melpomene}}\right)$ to attach sister species subtrees under the parent Heliconius genus node.
Why Bottom-Up Anchoring Succeeds Here:
  • Localized Error Isolation: Sequence noise or rare sequencing artifacts remain strictly confined within the local species block and cannot corrupt higher-level order/family topology.
  • Sub-Species Metric Precision: High-dimensional embedding resolution is focused locally on small parallel distance matrices ($m_k \ll N$), detecting subtle sub-species genetic signals that would be blurred by coarse global top-down splits.

6. Strategic Implementation Recommendations

  1. Hybrid Node Propagation: Use Medoids at the lowest species/strain level to eliminate sequence noise and misannotation outliers. Use 2-Wasserstein Distributional Representations or Phylogenetically Weighted Centroids when propagating up to Genus, Family, and Order levels.
  2. Pretrained Embedding Sources: Generate embeddings using zero-shot biological foundation models (e.g., InstaDeep Nucleotide Transformer 2.5B or HyenaDNA) to avoid sequence alignment dependencies.
  3. Benchmarking Pipeline: Validate against Insect DNA barcode / genomic datasets, assessing quality via combined Robinson-Foulds and Cophenetic Correlation (CPCC) scores.
