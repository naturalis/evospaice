The validation process we implemented involves checking a generated tree against the reference tree. The trees are loaded from newick format, and data structure checks are performed to ensure the validation can happen. Then we compute the first metric which is Robinson-Fould, to quantify the differences in topology between the two trees. For this metric, lower score indicates a closer match to the reference tree. Then, our second metric is about assessing whether the magnitudes of each tip node between the two trees are correlated. For this one, higher score is better. In this visualisation, we have 2 trees where the normalised RF is 23% and the correlation is 0.7. We can see in orange the branches that only exist in the reference tree, and in blue those only in the generated tree. In green, we can see that most of the topological structure of the trees match. The line-plot shows that the majority of the tip node magnitudes are well correlated between the two trees. Overall, these two metrics help us understand how biologically meaningful the generated tree from our methods is, compared to the reference tree.
