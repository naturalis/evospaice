The validation process in this demo involves checking a generated tree against the reference tree. The trees are loaded from newick format, and data structure checks are performed to ensure the validation can happen. Then we compute the first metric which is Robinson-Fould, to quantify the differences in topology between the two trees. Our second metric is about assessing whether the magnitudes of each node between the two trees are correlated. Overall, these two metrics help us understand how biologically meaningful the generated tree is compared to the reference tree.
