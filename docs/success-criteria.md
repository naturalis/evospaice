## Suggested success criteria

By the end of the hack:

* Generate a biologically reasonable tree for a non-trivial subset of the data.
* Demonstrate that branch distances preserve genetic similarity.
* Compare against a baseline/reference tree.
* Present a compelling visualization and story.

Not:

* Build a perfect global tree for millions of sequences.
* Resolve every taxonomic inconsistency.
* Build production infrastructure.
