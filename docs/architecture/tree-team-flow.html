Open decisions: representatives, roots, and merging

Representative: centroid means an average vector; medoid means a central observed member. Compare weighting, normalization, and which members can be selected. A child centroid is not necessarily an observed DNA record. Freeze each node's representative within a run.

Fair comparison: apply the same representative policy to both routes in each paired experiment, including weighting, normalization, and eligible-member rules. Different groups can yield different representatives. Test centroid versus medoid within each route too; do not attribute a difference to taxonomy when the representative methods also changed.

Root / attachment: a vector is not a tree root. NJ produces an unrooted tree, although the illustrations are drawn top-down to explain composition. Define where each child attaches and how connecting lengths account for distances already inside it.

Embedding-only strategy: vector grouping and recursive merging are a proposed scalable candidate, not a settled clustering algorithm. Do not use taxonomy for partitioning, topology, representative selection, or merging in this route. Labels may be examined afterward for evaluation.

Limits: subdivision must keep local calculations manageable. Never form a global all-pairs matrix. Do not force confident splits when the evidence is weak.

Scientific evaluation and vocabulary

Tip identity: agree whether a tip is a sequence record or a BIN (barcode cluster). Keep the source mapping and use the same meaning in both outputs.

Controls: compare with a trusted reference and a k-mer baseline, a non-neural DNA-fragment representation. Measure whether distortion increases deeper in the tree and whether short distances near the tips collapse. Agree numerical acceptance criteria with the science team.

Interpretation: embedding-derived lengths are not calibrated evolutionary time. A plausible picture or low local fitting error is not proof of a biologically sound merged tree.

NJ: Neighbor Joining, not nearest-neighbor search. Sibling: child of the same parent. Embedding: a numerical vector representing DNA.
