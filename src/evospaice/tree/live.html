Source versions, memory & computation contract

Refresh authenticates to Azure again, verifies SHA-256 checksums and every metadata row, then replaces the in-memory snapshot. It invalidates prior results even if refresh fails. There is one cancellable worker, a 180-second job limit, and no result cache. Only the latest result is retained.

Run merges rebuilds all descendants of the selected clade, not an induced subtree of a precomputed full tree. Ancestors above that clade are unary context only.
