Read the comparison correctly
  • The centroid, medoid, GSC-weighted and spherical-mean variants use cosine dissimilarity both within species and between species representatives.
  • Gaussian W2 uses Euclidean distances between individual raw vectors and W2 between species distributions. Its branch lengths cannot be directly compared with cosine lengths.
  • Singleton species have zero covariance. No artificial covariance or hidden jitter is added. GSC uses uniform weights only when all local branch lengths are zero.
  • All connectors use NJ with negative lengths clamped and counted, and midpoint rooting as a convention. There is no attachment-offset correction or global length refit.
  • All selected pairs are evaluated, including fitting data. These are descriptive comparisons, not held-out validation or confidence estimates.
  • The downloadable JSON also includes a least-squares scalar alignment of tree distances to cosine distances. It is fitted on these same pairs and is not biological calibration.
  • Uploaded trees keep their supplied rooting and branch lengths. Unary nodes introduced by pruning are collapsed, preserving retained leaf-to-leaf distances. Negative or non-finite lengths are rejected; missing lengths permit topology comparisons only.
  • Upload RF scores use the same unrooted split definition. Normalized RF is unavailable if neither tree has informative splits. Uploaded trees have no embedding correlation because the original pairwise embedding distances are not included in this page.
